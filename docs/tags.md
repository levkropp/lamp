# Metadata tags

LAMP 0.4.0-dev reads the opened file's tags with a handwritten reader (`src/tags.s`). After a successful open, `tags_read` walks the mapped file's metadata (it never fails the open) and keeps ten normalized keys as UTF-8: `title`, `artist`, `album`, `album_artist`, `date`, `track`, `disc`, `genre`, `comment` and `composer`. `lamp-cli --tags file` prints them as `key=value` lines, and playback prints them before starting. The Windows player shows "Artist – Title" (or the title alone) in place of the file name once a tagged file is open. The same reader keeps the file's [chapters](chapters.md) and [cover art](cover.md).

| Format | Tags read |
| --- | --- |
| MP3, MP1/MP2, ADTS AAC, AC-3, WavPack (raw streams) | ID3v2 tags at the start (several in a row), an APEv2 tag at the end or before an ID3v1 tag, then ID3v1/1.1 when nothing else was found |
| WAVE | `LIST INFO` (`INAM`, `IART`, `IPRD`, `ICRD`, `IGNR`, `ICMT`, `ITRK`/`IPRT`) and `id3 `/`ID3 ` chunks |
| AVI | `LIST INFO` as WAVE, except that `IPRD` is the product, not the album (as FFmpeg reads AVI) |
| AIFF/AIFC | `NAME`, `AUTH` (artist), `ANNO` (comment) and `ID3 ` chunks |
| AU | The annotation's `Title=`, `Artist=`, `Album=`, `Track=` and `Genre=` lines (the keys FFmpeg reads) |
| CAF | The `info` chunk's key/value strings, with Apple's keys (`year`, `track number`, `comments`) |
| FLAC | The first `VORBIS_COMMENT` block |
| Ogg Vorbis, Opus, FLAC | The comment packet of the first stream LAMP decodes, gathered across pages |
| MP4/M4A/MOV | `moov/udta/meta/ilst` and `moov/meta/ilst` items (`©nam`, `©ART`, `©alb`, `aART`, `©day`, `trkn`, `disk`, `©gen`, `gnre`, `©cmt`, `©wrt`) and QuickTime `udta` text atoms (`©nam` and so on with a length and language code) |
| Matroska/WebM | The Segment Info title and SimpleTags of Tags without a track, edition, chapter or attachment target (a TagLanguage other than `und` is skipped) |

RIFX, RF64/BW64, Wave64, FLV and MPEG-TS/PS tags are not read.

## Reading rules

Key names and precedence follow FFmpeg's demuxers, so `lamp-cli --tags` agrees with ffprobe's format tags (stream tags for Ogg):

- ID3v2.2–2.4: text frames (`TIT2`, `TPE1`, `TALB`, `TPE2`, `TDRC`, `TRCK`, `TPOS`, `TCON`, `TCOM` and their ID3v2.2 forms), `COMM` without a description, and `TXXX` frames whose description is one of the ten key names. The first frame of a key wins; only a text frame's first string is read. Text in Latin-1, UTF-16 with a byte order mark, UTF-16BE or UTF-8 converts to UTF-8; an unpaired surrogate ends the string. Unsynchronisation (whole tag or per frame, removing the 00 after each FF in frame data, with frame headers and sizes as stored), extended headers, data length indicators and grouping bytes are handled; compressed and encrypted frames are skipped. ID3v2.3 `TYER`, `TDAT` and `TIME` of four digits each merge into `YYYY-MM-DD HH:MM`. A `TCON` of `(N)` or `N` (after white space and a sign, as `sscanf` reads it) becomes the name of ID3v1 genre N.
- ID3v1/1.1: title, artist, album, year and comment to their first NUL with trailing spaces removed, an ID3v1.1 track number and the genre byte. Fields that are valid UTF-8 are kept as they are, as FFmpeg keeps them; others are read as Latin-1.
- APEv2 (version 1000 or 2000, with or without a header): UTF-8 text items; binary items and links are skipped.
- Vorbis comments: `KEY=value` with ASCII-insensitive keys (`TITLE`, `ARTIST`, `ALBUM`, `ALBUMARTIST`, `DATE`, `TRACKNUMBER`, `DISCNUMBER`, `GENRE`, `COMMENT` or `DESCRIPTION`, `COMPOSER`); repeated keys join with `;`.
- MP4: UTF-8 data items; `trkn` and `disk` as `N` or `N/total`; `gnre` as an ID3v1 genre name. Later items replace earlier ones, in file order. QuickTime text atoms with a Macintosh language code are read only when they are ASCII (FFmpeg converts Mac Roman).
- Every text-keyed format (APEv2, Vorbis comments, CAF, Matroska, `TXXX`) also accepts the ten key names themselves, as FFmpeg exposes such keys unchanged.
- Values end at their first NUL and are kept up to 4096 bytes, cut at a character boundary; empty values are not stored. `lamp-cli` prints control characters as spaces.

The genre names are the ID3v1 list (0–79) and the Winamp extensions (80–191), generated by `tests/generate-genre-table.py` into `src/tags_genres.inc`. Genre 133 is "Afro-Punk", the name current taggers use in place of the original slur.

## Differences from FFmpeg 6.1

- FFmpeg reads no APEv2 tags in MP3 files; LAMP reads them and lets them fill keys the ID3v2 tag left empty.
- FFmpeg leaves ID3v2.2 `TCM` and `TPA` under those names; LAMP reads them as composer and disc.
- FFmpeg passes ID3v1 bytes through even when they are not UTF-8; LAMP reads such fields as Latin-1.
- FFmpeg inflates compressed ID3v2.4 frames; LAMP skips them.
- Genre 133's name, as above.

Reading tags also made two decoders more tolerant: the MP3 reader skips consecutive ID3v2 tags and stops at a trailing APEv2 tag (with or without an ID3v1 tag after it) instead of rejecting the file.

## Verification

`python3 tests/verify-tags.py` ([report](../reports/tags-verification.json)) checks:

- Tags FFmpeg writes with non-ASCII values (including a supplementary-plane character and a newline) in 20 files: ID3v2.4, ID3v2.3, ID3v2 with ID3v1, and ID3v1 MP3; ADTS AAC with ID3v2; native FLAC; Ogg Vorbis, Opus and FLAC; M4A and QuickTime MOV; Matroska and WebM; WAVE and AVI INFO; CAF; WavPack APEv2; AIFF ID3 and text chunks; an AU annotation; FFmpeg's ID3v2.4 tag on MPEG Layer II. Each equals ffprobe.
- ID3v2 written by the test: version 2.2, every text encoding with surrogate pairs, described and plain comments in other languages, whole-tag and per-frame unsynchronisation, extended headers, data length indicators, an encrypted frame, `TXXX` keys, repeated frames, two tags in a row, odd genre strings and all 192 numeric genres, against ffprobe.
- ID3v1.1 with a track and genre, ID3v1 without a genre, Latin-1 ID3v1 text; APEv2 with ID3v2, alone (with a binary item) and before ID3v1; repeated, differently cased and malformed Vorbis comments; a comment packet over two Ogg pages cut at 4096 bytes; MP4 genre numbers and track/disc forms in ISO and QuickTime meta boxes; Matroska track-targeted tags; a WAVE `id3 ` chunk; CAF with Apple's keys.
- 1200 files with mutated tags neither crash nor hang.

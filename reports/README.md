The `macos-*` reports were recorded on macOS 26.4.1 ARM64. Their test-only adapters use UTF-8/Apple ABI, native protected-page sizes and sparse APFS files. Allocation-release checks count live malloc bytes instead of Windows private commit. The Vorbis reference encoder is built from pinned Xiph sources when FFmpeg lacks libvorbis. Terminal comparisons exclude only Darwin's transient PENDIN input state. The Mac reports do not claim a new official-vector run or Mac performance benchmark; the earlier official Opus vectors and WASAPI measurements retain their Windows scope. Open/drop/focus/fullscreen/Retina interactions still need comprehensive manual testing. See [Mac strategy, test adaptations and limits](../docs/macos.md).

The remaining `opus-*-verification.json` files record the 35-suite decoder stages. The RFC 6716 archive and RFC 8251 patch are hash-verified before reference compilation; the test-only modern framing helper retains its source hash and full license. Updated NLSF stabilization resolves the previous invalid vectors; the full resampler FIR history is checked without an uninitialized-tail exclusion. Component-only reports describe their own test boundaries. [Decoder documentation](../docs/opus.md) gives current interfaces, counts, tolerances and prerequisites. Older performance reports retain their measured build/object hashes and do not measure the new family 1 path.

[opus-modern-reference-progress.json](opus-modern-reference-progress.json) is a historical **incomplete** snapshot from before RFC 8251 updates. It records 42 tonal passes and the first noise mismatch. Hybrid folding resolves that regression; the current 51-file report above records the passing rerun. Cancellation coverage also found released COM pointers being reused; cleanup clears resource pointers and all cancelled-open checks pass.

WAV/FLAC, MP3 and Vorbis PCM reports include the current regression reruns. Older fuzz/stress/CPU benchmark reports retain their original scope and binaries; the seek benchmark above measures the current CRC change. The headless playback comparison adds actual WASAPI engine and comparator observations, with limits described in [its measurement notes](../docs/playback-benchmark.md). Historical executable-size fields in CPU benchmark reports refer to the earlier unbranded binary. These reports do not establish a universal advantage over mpv/VLC, or uninterrupted playback on other systems. PCM report `snr_db: null` means exact equality (infinite SNR) for those cases.

Older decoder snapshots were recorded on Windows. After the move to GNU-syntax sources, the portable suites were rerun on Linux x86-64 with the static build and reproduced every recorded count. The one exception is the `opus-decoder` frame categories: its synthesized test signals use the C library's `sin()`, so a few encoder decisions differ, still with zero reference error. The new E-AC-3, AC-3, MPEG-TS, track, QuickTime, Ogg-chain and robustness regression snapshots use Debian 12 x86-64 under QEMU emulation on ARM macOS, FFmpeg 5.1.9 and Wine 8.0 for Windows checks. The player snapshot uses Wine on Xvfb. Their timing fields are verification diagnostics, not performance measurements. See [technical test instructions](../docs/technical.md#verification) to reproduce the checks. The published v0.3.0 download retains the earlier four-format build; these development reports describe current source.
